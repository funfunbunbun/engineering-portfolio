# Selected code and source privacy

The public repository contains the newly written portfolio frontend, safe educational simulations, Mermaid diagram definitions and generated SVGs, selected technical figures, handwritten teaching excerpts and one reviewed FYP clip. It does not contain the original project applications.

The short explanatory examples cover a symbolic robotics transform, certainty-factor combination, a perceptron decision and a sentiment pipeline. They omit device addresses, physical motion commands, calibration, datasets, account records and credentials. The Nano demonstration is newly written browser code; its firmware and protected menus are excluded.

ONNX Runtime Web is distributed as a pinned dependency and checksum-matched runtime files. No model weights are hosted. The visitor may select a compatible local ONNX file, processed entirely on the device. A sanitized private model was used for local verification only. The sentiment demo remains an explicitly labelled feature-scoring example rather than the trained classifier.

Public images, the single selected video and runtime files require exact reviewed paths, signatures, sizes and SHA-256 values. Media originals, full reports, archives, saved models, databases, notebooks, credential files and logs remain prohibited. Build, tracked-file and history scans check common credential patterns without printing matched values. Browser tests verify no external data requests. Human review complements these checks.

The user’s existing public-publication approval covers this requested site revision. Separate public project repositories are deferred.
