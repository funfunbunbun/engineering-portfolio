# Interactive demo guide

Open **Demos** in the main navigation. All 16 cards link directly to the project’s controls. Every project also has a **Jump to interactive demo** action; the report figures remain below the interactive section.

| Project | Try this |
| --- | --- |
| Vehicle velocity | Adjust fictional distance and elapsed time; inspect the unit conversion. Original footage remains pending. |
| Smart Classroom | Change temperature, light, occupancy, or CO2; inspect the decisions and event log. |
| FPGA fan | Select duty cycle; compare the waveform, high-time, and conceptual fan. |
| PLC sorting | Select a category and step or run the sequence; inspect delivery totals. |
| Heart monitor | Toggle visitor/finger presence and simulate the interface sequence without health readings. |
| Pedestrian crossing | Request a crossing and step through mutually exclusive signal states. |
| Flood control | Move the water-level slider across an illustrative threshold. |
| Trolley CAD | Separate assembly groups and hide/show the basket, frame, and wheels. |
| ATM interface | Deposit/withdraw fictional credits and test validation. Reset clears the in-memory session. |
| Springs | Adjust force and stiffness to inspect ideal linear extension. |
| Battery study | Change the number of idealized series cells and load resistance. This is an electrical analogy, not battery chemistry or a recipe. |
| Robot recycling | Step through detection, grip, movement, release/count, and return. No real poses or controllers. |
| Planting trajectory | Adjust lift to cross/clear an illustrative 2D obstacle, then move along the curve. |
| Weather expert | Combine two positive rule-support scores offline; the score is not rain probability. |
| Sentiment analysis | Enter a fictional sentence and inspect a transparent, handwritten feature score. This toy is separate from the original trained MLP. |
| Neural classifiers | Toggle binary inputs and inspect an illustrative AND perceptron. |

These are newly written educational frontend models, separate from the academic evidence and original software. No live API, hardware connection, private model, personal dataset, or credential is needed. New input state remains in browser memory. Each demo provides Reset.

Validation: 23 React/core tests, five publication-policy tests, TypeScript, production build, and browser checks of all 16 pages at 320, 390, 768, and 1440 px. The public-text, tracked-file, image-checksum, and Git-history checks supplement human review.
